# Bird Snap

A friendly 3D bird photography game by MajorasPride. Ride through the park, listen for a call,
name the bird, then photograph it. It teaches bird watching and real camera skills as you play.

- **Status:** prototype, Level 1 (The Park). Not live yet.
- **Run it:** download `index.html` and open it in a browser (phone or PC).
- **Handoff and next steps:** [HANDOFF.md](HANDOFF.md)

| Branch | What it is |
|---|---|
| `main` | v0.2: the approved 3D on-rails base |
| `v0.4-preview` | Easy mode (point and shoot, Photo School) plus Real Shoot mode (shutter, aperture, ISO, manual focus) |

Planned levels: Park, Wetland, Rainforest, Coast, Mountain.
